# Teslasuit Data Manager — Grasshopper Clusters

A collection of Grasshopper **User Objects (.ghuser)** developed as part of doctoral research Making Motion Tangible: Embodied and Critical Research at the Human-Machine Interface". These clusters provide tools to manage, visualise, and process Teslasuit IMU data in Grasshopper.

---

## Features

- 7 ready-to-use clusters for data import, mapping, and analysis  
- Toolbar tab: **Teslasuit Data Manager**   
- Compatible with Rhino 7  

---

## Installation (Grasshopper)

1. Download or clone this repository.  
2. Open Grasshopper in **Rhino 7**.  
3. Copy all `.ghuser` files from the `UserObjects` folder of this repository into your Grasshopper **UserObjects folder**:

   **Mac path (Rhino 7):**

~/Library/Application Support/McNeel/Rhinoceros/7.0/Plug-ins/Grasshopper/UserObjects


4. Restart Grasshopper.  

The clusters will appear in the toolbar under the tab:  
**Teslasuit Data Manager**.

---

## Requirements

- **LunchBox plugin** for Grasshopper (used for the “Read CSV” component). Ensure it is installed before using the clusters.

---

## Usage

1. Drag and drop the clusters onto your Grasshopper canvas or use the toolbar tab.  
2. Open and reference your excel file.  
3. Explore the outputs to visualise or work parametrically with the captured motion data.
